SafeHer AI — Frontend Client

Mobile-first responsive web client built with Next.js and Tailwind CSS, incorporating trauma-informed UX design, privacy controls, and dynamic tri-lingual localization (Sinhala, Tamil, English)[cite: 18, 24].

## Tech Stack
- **Framework**: Next.js v15 (App Router, Client-Side State Management)
- **Styling**: Tailwind CSS v4 with PostCSS[cite: 21]
- **Icons**: Lucide React
- **Language**: TypeScript[cite: 24]

## Key UI/UX Capabilities
- **Quick Exit**: Single-click escape redirecting immediately to a neutral domain (`google.com`).
- **Tri-lingual Localization**: Seamless runtime switching across English, Sinhala, and Tamil across all screens[cite: 18].
- **Exploratory AI Framing**: Disclaimers presenting AI output as preliminary guidance rather than legal or clinical findings[cite: 19, 20].
- **Human-in-the-Loop Agency**: User controls allowing review, correction of AI categories, and approval before sharing[cite: 19, 20].
- **Consultation Lifecycle Tracker**: Status progression tracking professional matching through to encrypted audio consultation readiness[cite: 23, 24].
- **Emergency Pathways**: Quick access to national hotlines (119 Police, 1938 Women's Helpline) alongside verified specialists[cite: 21].
